unlock 便携版（Windows x64）

一、安装
双击最外层的“安装.bat”。请保留所有子文件夹一起使用。

安装过程：
1. 已有 Node.js 18 或更新版本：直接跳过 Node.js 安装。
2. 否则通过 PowerShell 从 Node.js 官网下载 LTS，校验 SHA256 后自动安装。
3. 下载失败时，使用 installers 中附带的离线安装包。
4. 安装 unlock，并配置当前用户 PATH。

Node.js 安装可能弹出管理员确认；unlock 本身安装无需管理员权限。
不依赖 winget，不需要手动下载安装包。下载的临时文件会自动清理。

二、使用
安装完成后关闭旧终端，重新打开 PowerShell。

原位解密单个文件：
unlock "D:\资料\示例.txt"

递归识别文件夹内的加密文件并原位解密：
unlock "D:\资料"

普通文件在文件夹扫描时跳过。匹配文件会被替换，重要资料请先备份。
电脑需要具备 Node 能读取明文的环境条件；本工具不提供解密密钥。

三、文件结构
安装.bat       双击安装入口
使用说明.txt   本说明
bin            unlock.js 和 unlock.cmd
setup          自动安装脚本
installers     官方 Node.js Windows x64 离线安装包（已校验 SHA256）

unlock 安装位置：%LOCALAPPDATA%\Programs\unlock-cli
如果不安装，可在 bin 文件夹打开终端，运行 .\unlock.cmd "目标路径"。
